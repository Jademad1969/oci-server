About System & Organization

Discover Islam Society - Bahrain

جمعية اكتشف الإسلام (Discover Islam Society)

نظام إدارة الاستقطاعات الآلية ومتابعة المتبرعين، المصمم خصيصاً لتحديث وترقية النظام القديم (Oracle Developer 6i) إلى بنية ويب حديثة وآمنة تعمل على الحوسبة السحابية. يتيح النظام إدارة المتبرعين، تدقيق أكواد البنوك، مطابقة كشوف البنوك عبر ملفات CSV، ومتابعة الاستقطاعات المتأخرة بدقة متناهية.

⚡

Modern Stack

Built with FastAPI, PostgreSQL 16, Python, Tailwind CSS & Alpine.js.

🔒

Secure RBAC

Role-based access control with session security and audit logs.

📊

Comprehensive Reports

Real-time financial reconciliation and donor followup analytics.
